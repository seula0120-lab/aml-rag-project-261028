1. Ollama 연결

아직 연결하지 않았습니다.

처음 한 번만 설정하기

터미널에서 차례로 실행하세요.

ollama pull bge-m3 ollama pull qwen2.5:7b

권장 열기 방법: 이 파일과 같은 폴더의 RAG_열기.command를 더블클릭하세요. 내 컴퓨터 안에서만 쓰는 작은 웹 서버(http://localhost:8000)로 열립니다. Ollama는 localhost 주소에서 오는 접속을 기본으로 허용하므로 따로 설정할 필요가 없습니다.

터미널로 직접 열 때 (이 폴더에서):

python3 -m http.server 8000 --bind 127.0.0.1

주의: 예전 안내의 OLLAMA_ORIGINS="*"는 내가 여는 모든 웹사이트가 내 컴퓨터의 Ollama를 호출·조작할 수 있게 하므로 쓰지 마세요. 이미 설정했다면 아래로 되돌리고 Ollama를 다시 켜세요.

launchctl unsetenv OLLAMA_ORIGINS

Ollama 없이도 숫자 질문(계산 도구), "자료 보기", 단어 검색은 됩니다. 쉬운 설명 생성만 Ollama가 필요합니다.

    4. 검색 설정

    AML 통합 질의응답 RAG-5 데이터 v2

    숫자를 묻는 질문(반응률, 사망률, 생존기간, 환자 수)은 이 파일 안의 원자료 3,000명으로 계산 도구가 바로 계산하고, 뜻·기준·방법을 묻는 질문은 데이터 사전·지식 문서·분석 노트에서 찾아 답합니다. AI(Ollama)는 계산 결과와 찾은 자료를 쉬운 말로 풀어 쓰기만 하고, 답을 내기 전에 프로그램이 숫자와 표현을 한 번 더 검사합니다.

    왼쪽에서 Ollama를 연결하면 내장 자료의 검색 준비가 자동으로 끝납니다. 오른쪽 질문 목록에서 질문을 눌러 시작해 보세요. 직접 입력해도 됩니다.

    연구·학습용 도구입니다. 데이터는 교육용 합성 데이터이며 실제 진료 판단에 쓸 수 없습니다. 숫자 질문은 계산 도구가 원자료로 계산합니다([1] 계산 도구). 답변 아래 ‘검사’ 줄과 출처 구절을 함께 확인하세요. 각 질문은 독립적으로 처리됩니다.

    [RAG-5] 정답은 이 파일의 자료가 아니라 원본 CSV에서 따로 계산해 넣었습니다(스스로를 채점하지 않도록). 숫자는 ‘어딘가에 있으면 통과’가 아니라 맞는 군 옆에 있어야 통과합니다(A·B 값을 뒤바꾸면 실패).

    내장 질문 세트로 이 RAG의 답변을 자동 채점합니다. 왼쪽의 답변 모델, 임베딩 모델, 참고할 구절 수 설정을 그대로 씁니다. 결과는 이 브라우저에만 저장되고, CSV로 내려받을 수 있습니다.

    Ollama는 로컬이라 0이 기본값입니다. API 모델과 비교하려면 단가를 넣으세요.

    실행 기록 (베이스라인과 비교)

    채점기 자체 점검

    미리 만든 좋은 답과 나쁜 답을 채점해서 채점기가 기대대로 판정하는지 확인합니다. Ollama가 없어도 됩니다.

    부품 검증 (프로그램이 맞게 계산하는지)

    검색, 글 자르기, 단어 뽑기, Ollama 통신 오류 처리, 채점기, 내장 자료 일관성을 정해진 입력과 기대 결과로 확인합니다. Ollama 없이도 됩니다. 아래 "실제 Ollama 확인"은 진짜 서버에 연결해서 확인합니다.

    ※ 원자료 CSV를 불러오지 않았다면 '계산 도구' 등 원자료가 필요한 시험 약 20개가 실패로 표시됩니다(정상). 불러온 뒤에는 모두 통과합니다. 파일을 직접 열면 'Ollama 통신' 1개도 실패합니다 — RAG_열기.command로 여세요.

    평가 질문과 채점 기준

    통과 기준: 답이 있는 질문은 ① 필수 키워드를 모두 포함하고 ② 군별 값이 맞는 군 옆에 있고(슬롯) ③ 거절하지 않고 ④ [자료]에 없는 숫자가 없고(질문 문장은 근거로 치지 않음) ⑤ 맞는 자료 번호를 인용하고 ⑥ ‘효과적’ 같은 인과 표현·%p↔% 혼동이 없어야 합니다. 근거가 없는 질문(이식·MRD·개인정보·치료 상담 등)은 거절해야 합니다.

    질문 목록

    누르면 바로 질문하고 답이 나옵니다. 답한 질문에는 ✓가 붙습니다.
